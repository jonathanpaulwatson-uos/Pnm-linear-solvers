# Probabilistic Numerical Methods for Linear Solvers
The repository contains Python implementations of classical stationary methods (Richardson, Jacobi, Gauss–Seidel, SOR, and weighted Jacobi), along with an analysis of the convergence convergence behaviour and uncertainty quantification. All results reported in the dissertation can be reproduced using the scripts provided.

## Contents
- fuelefficiencyv2.py - contains different numerical methods along with the analysis of the results

## Requirements
Python 3.10

Seaborn, NumPy, SciPy, Matplotlib, sklearn.preprocessing

## How to run
Run `experiments.ipynb` in Jupyter Notebook.
