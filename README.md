# Probabilistic Numerical Methods for Linear Solvers

Python implementation and analysis developed as part of my MMath Mathematics dissertation at the University of Southampton.

## Overview

This project investigates numerical methods for solving systems of linear equations, with a particular focus on convergence behaviour and uncertainty quantification in a regression setting. It combines numerical linear algebra, statistical methods and Python implementation to investigate the behaviour of classical iterative solvers and probabilistic approaches to numerical computation.

## Methods

The project includes implementation of the following iterative numerical methods:

- Richardson iteration
- Jacobi method
- Gauss–Seidel method
- Successive Over-Relaxation (SOR)
- Weighted Jacobi

## Technologies

- Python
- NumPy
- SciPy
- Matplotlib
- Seaborn
- scikit-learn

## Project Background

This work formed part of my final-year MMath Mathematics dissertation at the University of Southampton. My dissertation focused on probabilistic numerical methods and their application to regression and uncertainty quantification. The project involved translating mathematical methods into Python implementations and using computational experiments to analyse their behaviour.

## Repository Structure

`probabilistic_linear_solvers.py` contains the Python implementations of the numerical methods and the associated analysis.
